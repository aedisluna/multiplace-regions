# MultiPlace — пакеты карт

Публичные данные OpenStreetMap и каталог загрузок. Пользовательские вложения, запросы, геолокация и исходники приложения сюда не публикуются.

## Общая классификация POI — 12 октября 2026

[Пакеты Москвы](https://github.com/aedisluna/multiplace-regions/releases/tag/poi-categories-2026-10-12): до ЦКАД — 383 366 POI / 109 категорий; стартовый район — 56 110 POI. Общие правила выделяют врачей, бары/пабы, скамейки, почтовые ящики, велопарковки и другие типы по OSM-тегам. Все исходные ID, координаты, адреса, бренды и собственные имена сохранены. Названия безымянных категорий уточнены. Услуги: 99 243 → 4 611 записей. Новая типология не подтверждает актуальность всех заведений.

[Каталог приложения](https://github.com/aedisluna/multiplace-regions/releases/latest/download/regions.json). В приложении явно выберите Скачать и использовать либо установите .mpregion из файла. После установки поиск/карта работают офлайн. Архивы совместимы с MultiPlace 0.11+. Новый стартовый район входит в APK 0.15.1. Старые архивы сохранены в Releases.

До ЦКАД: bbox 36.82–38.62 / 55.28–56.24, zoom 8–15. Стартовый район: 37.575–37.72 / 55.725–55.825. Это прямоугольные покрытия, не вся Московская область. Адрес Рядом — приблизительный ориентир, а не подтверждённый дом. В архиве manifest, PMTiles, SQLite, стиль, подписи/шрифт. Размеры/SHA/даты — в manifest, [источники](SOURCES.json). POI: снимки OSM France от 9 октября; basemap Protomaps от 8 октября. Карта и подписи этой итерацией не менялись.
